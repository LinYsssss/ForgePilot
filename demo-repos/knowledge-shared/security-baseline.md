# 安全基线

> 适用范围：全部服务，与具体业务领域无关。各服务的专属约定见各自仓库 `docs/` 下的文档。

## 1. 数据库访问

参数化查询是访问数据库的唯一允许方式。变量一律经绑定参数传入，不得以字符串
拼接、格式化或模板替换的方式进入语句文本。这一条对 `WHERE`、`IN` 列表和批量
写入同样成立。

表名、列名、排序方向这类无法绑定的成分，必须映射到代码内维护的固定白名单，
用调用方传入的值去查表，而不是把它拼进语句。白名单之外的输入直接拒绝。

## 2. 身份与权限

身份与权限必须来自认证上下文，不得来自请求参数。调用方可以声明自己想访问
什么，但不能声明自己是谁、属于哪个数据边界。凡是从请求体或查询串里读出
身份标识再据以放行的写法，都等同于把授权决定交给了攻击者。

「已认证」不等于「已授权」。按标识操作单条资源的接口，除了校验登录态，还必须
校验该资源确实落在当前调用方的数据边界内，否则就是可以直接遍历的越权入口。

## 3. 口令与令牌

口令必须使用为口令场景设计的、可调工作因子的慢哈希算法存储，并配随机盐。
通用摘要算法为快速计算而生，不具备抗碰撞与抗暴力破解所需的性质，禁止用于
口令、令牌或签名。

令牌必须由密码学安全的随机源生成，具备有效期与失效手段。可预测的自增值、
时间戳或用户信息编码不得充当令牌。

## 4. 凭据管理

密钥、口令、证书私钥禁止出现在源码、配置样例与版本历史中，一律经环境变量
或密钥管理服务注入。前端产物随页面公开分发，任何写进去的凭据都视同已泄露。

一旦发生泄露，轮换凭据是唯一有效的补救，删除提交记录不是。

## 5. 外部回调

对外暴露的回调入口必须验签，用共享密钥或公钥校验报文完整性，并带时间窗与
重放防护。不得仅凭来源地址、路径难以猜测或报文里自带的状态字段就信任内容。

## 6. 敏感字段

敏感字段在响应与日志中必须脱敏，只返回业务确需的最小片段。异常栈、调试接口
与监控埋点同样受此约束，它们是最常见的绕过点。
