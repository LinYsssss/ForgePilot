# 前端样式规范

> 范围：官网、控制台、运营工作台三套 Web 界面。原生端样式另行约定。

## 1. 类名

统一 BEM：`block__element--modifier`。块名用名词短语，如 `goods-card`、
`filter-bar`；修饰符只描述外观状态。工具类以 `u-` 开头，布局容器以 `l-`
开头，两者不得与 BEM 块混写。

## 2. 样式变量

颜色、字号、圆角、阴影一律走变量，不写字面量。命名为「色板名-档位」，
如 `--brand-500`、`--neutral-200`。主色 `--brand-500` 取 #2F6BFF，
中性色十档从 #FFFFFF 递进到 #16181D。语义变量再引用色板变量，
如 `--text-muted: var(--neutral-500)`，页面里只写语义变量。

## 3. 间距

4px 基准，刻度取 4/8/12/16/24/32/48/64，不出现 6px、18px 这类值。
卡片内边距 16px，卡片之间 24px，模块之间 48px。

## 4. 断点

移动 <768px，平板 768–1023px，桌面 1024–1439px，宽屏 ≥1440px。
媒体查询一律 min-width 向上叠加，禁止与 max-width 混用。

## 5. 图标

只用 24×24 网格的线性图标，线宽 2px，导出 SVG 时去掉自带填色，
由 `currentColor` 继承文字颜色。列表内缩放到 16px。

## 6. 暗色模式

由根节点 `data-theme="dark"` 整套切换语义变量，组件内不写暗色分支。
暗色下不要直接反转亮色值，中性色需重新取样，正文对比度不低于 4.5:1，
大字号不低于 3:1。纯黑底一律不用，底色取 #16181D。
