# 接口约定

> 适用范围：tenant-user-center

## 1. 响应格式

```json
{ "code": 0, "errorCode": "OK", "message": "success", "traceId": "...", "data": {} }
```

错误时 `code` 非零，`errorCode` 为稳定字符串标识。**客户端应基于 `errorCode` 分支，不要解析 `message`。**

## 2. 分页

所有列表接口分页，默认每页 20，上限 100：

```json
{ "items": [], "page": 0, "size": 20, "totalElements": 0, "totalPages": 0 }
```

排序字段必须走白名单，**禁止把客户端传入的字段名直接拼进 SQL**。

## 3. 输入校验

- 所有字符串字段必须限长。
- 用户名字符集限定为 `[A-Za-z0-9._-]`，长度 3~64。
- 邮箱、手机号必须格式校验。
- 数值必须校验范围，禁止负数。

## 4. 输出与渲染

- **用户可控内容（昵称、备注、标签）一律按文本渲染，禁止 `innerHTML`。**
- 手机号、邮箱在列表接口中脱敏，仅详情接口对有权者返回完整值。
- 错误响应不得回显 SQL、内部路径、堆栈。

## 5. 密钥

- API Key、数据库密码、令牌签名密钥一律从环境变量读取。
- **禁止出现在前端代码中** —— 前端产物是公开的。

## 6. 限流

- 普通接口每 IP 每分钟 120 次。
- 登录接口见 `auth-policy.md` 第 3 节。
- 导出接口每租户每小时 5 次。
