# 安全规范

> 适用范围：payment-settlement-service

## 1. 外部回调

- 所有来自银行 / 支付渠道的回调，**必须在解析业务参数之前完成 HMAC 验签**。
- 验签必须基于**原始请求字节**，不能基于反序列化后再重新序列化的结果。
- 验签失败一律返回 401，且**不得把请求正文写入日志或数据库**。
- 回调必须幂等：同一 `event_id` 重复到达只处理一次。

## 2. 出站请求

- 所有出站 HTTP 请求的目标主机必须在配置的白名单内。
- 禁止把用户可控的字符串直接拼进 URL 后发起请求。
- 禁止请求内网地址、回环地址与云元数据地址（`169.254.169.254`）。

## 3. 凭据

- 数据库密码、HMAC 密钥、渠道 API Key 一律从环境变量读取，**禁止出现在代码或配置文件的默认值中**。
- 日志中禁止输出密钥、令牌、Authorization 头、完整卡号与银行账号。

## 4. SQL

- 禁止字符串拼接 SQL，一律使用参数绑定。
- 所有查询必须带 `tenant_id` 过滤。

## 5. 权限

- 管理类接口（`/admin/**`）必须校验调用方具备 `ADMIN` 角色。
- 仅校验「已登录」不构成授权，必须校验资源归属。

## 6. 日志与留存

- 回调正文、完整报文不得落库，只保留哈希与元数据。
- 审计日志保留 180 天，其中不得包含敏感字段明文。
