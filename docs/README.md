# ForgePilot 文档索引

本目录保存面向使用者的项目文档：架构、数据库、接口、消息队列、RAG/AI 审查设计、部署与配置、本地联调和服务器部署。

## 推荐阅读顺序

| 顺序 | 文档 | 用途 |
| --- | --- | --- |
| 1 | `01_系统架构设计说明书.md` | 理解整体架构、模块和部署结构 |
| 2 | `02_数据库设计说明书.md` | 表结构和数据关系 |
| 3 | `03_接口设计文档.md` | API 字段与前后端联调约定 |
| 4 | `04_MQ与异步任务设计.md` | RabbitMQ、重试、死信、幂等 |
| 5 | `05_RAG与AI审查设计.md` | 检索、Prompt 结构、AI JSON 输出 |
| 6 | `08_部署环境与配置清单.md` | 环境变量与配置项 |
| 7 | `11_本地开发与联调手册.md` | 本地启动、联调和常见问题 |
| 8 | `12_服务器部署与演示手册.md` | 云服务器 Docker 部署与演示验收 |
| 9 | `13_数据生命周期与备份恢复.md` | 卷职责与清理边界、备份恢复、ai_call_log 留存口径 |

> 项目总览、快速开始和配置说明见根目录 `README.md`。
> 需求背景见根目录 `代码仓库智能审查平台_需求规格说明书.md`。
