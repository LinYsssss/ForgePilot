# RepoSage 智能代码审查平台文档索引

## 1. 文档用途

本目录保存项目需求、架构、数据库、接口、消息队列、RAG、AI 审查、部署、测试、演示数据、开发联调和答辩材料。

## 5. 暂缓开发功能

以下功能不进入第一版主线：

- CodeBERT 微调。
- GitHub / GitLab PR 自动评论。
- 多语言代码审查。
- 自动生成 Patch。
- 企业级多租户。
- 复杂规则引擎。

这些功能适合作为后续扩展和面试加分点。
