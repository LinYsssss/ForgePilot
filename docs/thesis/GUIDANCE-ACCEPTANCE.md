# 实现建议模块的功能验收与输出观察

## 一、目的与证据定位

本节记录一次性实现建议模块的功能验收及少量输出观察，用于说明系统能否将已保存的需求和项目知识转化为可阅读、可核对的建议。**它不是代码审查准确率实验，也不是开发效率或总体模型质量评测。** 正式三臂评测、去提示敏感性分析、PR 演练和稳定性复测仍按各自的数据集与口径报告，不合并分母。

系统在 `guidance-2` 中增加了建议概览、待确认事项、版本标识和本地导出，并在页面中保护未保存内容及过期请求。随后 `guidance-3` 仅收紧文本指令：减少非阻塞提问，区分已确认约束与条件式建议，要求落实适用知识中的硬约束，并避免重复步骤。返回 schema、检索机制、权限和调用路径均未改变。

本次使用已部署提交 `54e2953`，没有为整理本节重新调用模型。完整过程见[发布与验收记录](../../.trellis/tasks/archive/2026-10/10-02-guidance3-tightening/release-validation-20261003.md)。

## 二、方法

在生成前固定三个样例，各发起一次真实建议生成请求：

1. **发货校验**：既有演示需求，用于复查先前已发现的输出问题，并与保留的 `guidance-2` 单次结果对照。
2. **租户查询**：另一项目中具有明确租户隔离、参数绑定、分页和排序规则的既有需求，此前未用于本轮指令调优。
3. **CSV 导入草稿**：在隔离测试项目中新建信息不足的草稿，不配置知识，用于观察模型是否识别缺失决策。CSV 导入只是输入需求，**并非 ForgePilot 新增或实际执行了导入用户业务**。

前两例通过认证 API 调用，第三例在真实浏览器中点击生成。后台审计记录了三次实现建议和三次 embedding 成功调用，没有反复生成后挑选较好结果。浏览器边界检查另使用四次受控响应回放，不计入模型样例，也没有增加后台模型调用。

正文字符数按 `summary` 和 `questions/checklist/rules/risks` 中各字符串的 Python `len` 相加，排除知识摘录、JSON 标点与页面文案；它只表示文本规模，不等于阅读时间或内容质量。各例耗时来自客户端等待，入口和输入规模不同，不据此进行性能排名。

## 四、输出的定性观察

**发货样例有改善，也保留了反例。** 授权检查进入了实施步骤，部分方案采用条件式表达。但回答一处表示无法取得风控字段时只能落实地址和电话完整性，另一处又要求确认前不得绕过风控校验，仍存在约束弱化和同一回答内的表达冲突。

**租户查询样例较完整地落实了已有约束。** 输出包含认证上下文中的租户标识、仓储边界、计数和 JOIN 的隔离、参数绑定、分页上限及脱敏。不过，仍把可以查看现有实现确认的事实列为阻塞问题，并在末尾重复汇总测试要求。

**信息不足的草稿能够触发合理提问。** 模型识别了 CSV 格式、重复和失败处理等未明确事项，未把猜测的现成代码接口当成事实。与此同时，同步/异步、结果留存或错误明细下载等讨论不能自动演变成新增功能范围，仍需人工取舍。

这些观察说明，本轮可以确认程序功能可用、部分表达更集中，但**不能宣称“知识硬约束可靠落实”“输出全面变短”或“建议整体质量提高”已得到验证**。系统保留需求、参考资料和人工处置边界，是为了让用户能够核对模型建议，而非替代人的判断。

## 五、浏览器功能验收

使用隔离容器中的 Playwright 1.63.0 和 Chromium 153.0.8010.12，通过本机映射入口访问已部署前端；采用减少动画模式，检查 1365px 桌面和 390px 窄屏视口。

已验证：未保存内容时禁止生成；等待状态明确；参考资料默认折叠且可展开；实际剪贴板内容与下载的 Markdown 一致；保存同一修订 ID 的草稿后旧建议失效；晚到响应回放不能恢复旧结果；受控失败时保留上一份有效建议。真实生成流程没有脚本/控制台错误，390px 下没有横向页面溢出。

这属于实现建议区的限定验收，不是全站浏览器兼容性测试。没有覆盖公开域名完整浏览器登录流程、其他浏览器、手机实机、768px 档位、默认完整动画模式或系统拒绝剪贴板权限的实操场景。较长的待确认内容仍占据结果区首屏，大屏下无权限面板留有较多空白，阅读布局仍有改善空间。

## 六、有效性威胁与数据可用性

- 仅三个非随机样例，且发货案例的问题参与了指令改进，不是新的无偏测试集。
- 每个条件只有一次输出，不能估计运行间方差；相同配置的提供方也不保证确定性。
- 没有逐条建议的独立质量真值，没有开发者对照组或用时研究，因此不计算准确率、召回率或效率提升。
- 定性检查由单个检查者完成，可能带有判断偏差；问题数和字符数不能代替质量评价。
- 公开 CSV 仅提供摘要数值与来源指纹。脚本可以复核公开数据完整性、汇总和本节表格，**不能仅凭哈希证明私有原文、原始计数或语义判断正确**；进一步核实需要作者提供相应原始证据。

原始回答、知识片段、截图、登录信息和备份仍留在受限本机目录。测试项目已通过正常 API 归档；只有新测试草稿在失效检查中修改了标题，两个既有需求未改。正式评测和历史 CSV 均未覆盖或重跑。
