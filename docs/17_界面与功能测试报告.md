## 4. 一键冒烟结果

命令：

```text
.\scripts\smoke-backend.ps1 -BaseUrl http://localhost:8080
```

最近一次结果：

```text
Health           : UP
RepositoryStatus : ACTIVE
KnowledgeStatus  : INDEXED
SearchMatches    : 1
TaskStatus       : SUCCESS
OverallRisk      : HIGH
FirstIssue       : AUTH_RISK
FeedbackId       : 1
MqLogCount       : 0
AiLogCount       : 4
```

说明：`MqLogCount=0` 是 dev inline 模式的正常表现，因为任务未经过 RabbitMQ。生产模式设置 `REVIEW_INLINE=false` 后才会产生 MQ publish/consume/retry/dead 日志。

## 8. 已知限制

| 限制 | 影响 | 后续处理 |
| --- | --- | --- |
| Docker 未安装或不在 PATH | 无法在当前机器验证容器部署 | 到云服务器或安装 Docker 后执行 compose 验收 |
| 真实大模型 API 未实测 | 不能证明线上模型调用稳定性 | 准备兼容 OpenAI 协议的 Key 做一次验收 |
| pgvector 生产模式未容器验收 | 生产 RAG 仍需验证 | Docker 环境中上传文档并检索 |
| 私有仓库 Token 未做真实仓库验收 | 当前已注入 HTTPS Git 认证头，但缺少真实私有仓库测试 | 用 GitHub/GitLab/Gitee 私有仓库做服务器验收 |
| 模型训练样本较少 | 分类器只适合演示 | 后续用反馈数据扩充样本 |

## 9. 结论

RepoSage 当前版本已经具备本地完整演示能力：

- 能启动后端和前端。
- 能完成核心审查链路。
- 能展示 RAG、AI 审查、报告、反馈、AI 日志。
- 能训练并加载轻量风险分类模型。
- 模型服务开启后，后端审查链路能产生 `MODEL_RISK` 日志，说明轻量模型风险预判已进入主流程。
- README、答辩脚本、部署文档和测试报告已经具备。

剩余工作集中在服务器部署验收和真实大模型/pgvector 生产链路验证。
