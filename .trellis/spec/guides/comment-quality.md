# 注释质量标准

> 来源：08-13 生产加固任务步骤 7/8（backend 252 文件、sandbox-runner 48 文件、frontend、model-service
> 的注释治理实测）。目标是**可读**，不是**有注释**。

---

## 1. 注释写「为什么」，不写「是什么」

代码已经说清楚做了什么。注释要补的是代码说不出口的东西：

- 为什么**不**用那个显而易见的写法（曾经踩过什么坑）；
- 这个取值/顺序/条件是从哪条约束推出来的；
- 违反它会以什么形式失败。

反例（禁止）：`/** 用户 id */ private Long userId;`——零信息量，还会随字段改名腐坏。

## 2. 没话可说就不要写：豁免是正当结论

实测数据：backend 252 个无中文文件里，**只有 59 个真有英文散文注释**，其余 193 个一句注释都没有——
其中 108 个不到 40 行（record / enum / DTO / 派生查询仓储 / JPA 实体）。

对这些**结构自明**的文件批量加注释，产出的必然是第 1 节的反例。**豁免它们是正确答案。**

判据：字段名与类型是否已经承载了全部语义？是 → 豁免；否（存在反直觉的命名或约束）→ 补。

## 3. 豁免清单必须区分两种「没写」

写豁免清单时不要把两类混成一句「均无需注释」：

| 类别 | 含义 | 可信度 |
|---|---|---|
| 结构自明 | record/实体/仓储/接口/异常，签名即语义 | 硬结论 |
| **本轮未逐个评估** | 普通实现类，只是现在没注释 | **不是**「已核定无需」 |

08-13 的清单里 120 个属前者、72 个属后者，分开写明。
把后者说成前者，等于发一张假的健康证明。

## 4. 翻译注释时必须复核断言，别把错话译得更流畅

治理中实测撞到两处**内容本身是错的**注释：

- `AgentOutboxScheduler` / `AgentSchedulingConfig` 声称「测试上下文完全不受影响」——
  实为打开调度的测试上下文会被 Spring 缓存复用，其调度线程在该类结束后继续动同一张表
  （这正是当天一个 CI 顺序性失败的根因）。
- 合同声称需要「纹理加载失败时降级」——实现根本没有外部纹理，该失败态不存在。

**注释是会过期的断言。** 逐字翻译等于把错误固化下来并显得更权威。
译到一句就顺手验一句；验伪了就改内容，并在提交信息里点名。

## 5. 跨模块镜像件的注释必须逐字一致

`SandboxJob` / `SandboxJobSigner` / `WorkspaceArchiveReference` 等在 backend 与 sandbox-runner
各有一份同构镜像。**两侧注释必须是同一份译文**——各译各的会让下次比对无法判断二者是否仍然同构，
而这类文件恰恰是靠「肉眼可比对」来防漂移的。

## 6. 用正则数注释会数错，先验证再行动

`//` 会出现在字符串字面量里。实测两类误判：

- `"http://apache.org/xml/features/..."` → 让两个零注释的 Normalizer 混进「有英文注释」名单；
- `"archive://workspace/job.tar.zst"` → 同理误判三个 sandbox 测试文件。

**统计结果只是线索，不是事实。** 按统计动手前先抽查几个，否则会给零注释文件"翻译"不存在的注释，
或据此写出错误的完成度声明。

## 7. 补注释的优先级：反直觉 > 安全关键 > 其它

有限精力先给这两类：

- **易被读反的命名**。例：`targetDisappeared` 看着像「目标文件不见了」，
  实为「缺陷特征在打补丁后消失」，即补丁**修好了**问题——读反会把安全判断整个颠倒。
- **安全关键但无解释的配置**。例：两个 FindingNormalizer 里整套 XXE 关闭配置原本零注释；
  少关一项即可诱导后端读本地文件或外连，而代码表面看只是几行 `setFeature`。

## 8. 完成判据要能机器复核

治理类工作必须留下可重跑的判据，否则"做完了"无法验证：

```bash
# 仍不含中文的文件
LC_ALL=C.UTF-8 grep -rLP "\p{Han}" <src> --include=*.java
```

再叠加一条「仍含英文散文注释的文件数 = 0」的脚本判据（见
`.trellis/tasks/08-13-production-hardening/research/profile-comments.py`），
两者合起来才说明白：**全覆盖**，还是**覆盖 + 成文豁免**。
