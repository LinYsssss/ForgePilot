# 论文材料：演示仓复验与 Halo 重放评测

## Goal
把 2026-09-22 的两次线上评测（演示仓 15 PR 在锚定校验器下重跑 + 闭环 + 抑制继承；Halo 24 个真实上游 PR 重放）整理为 `docs/thesis/` 下可独立复算的论文材料，格式与既有生产复验材料一致。

## Requirements
- 每个数据集一份紧凑 CSV（只含 id、状态、计数、时延、token、哈希等，不含 Prompt、模型正文、Diff、知识原文、凭据）、一份中文叙述、一份仅标准库的复算脚本，CSV 以 SHA-256 钉住。
- Halo 材料附 11 条 Finding 的人工判定表（真/可辩/假）与依据，判定依据只引用公开的上游代码与 PR。
- README 表格增加新材料；`DEFENSE-GUIDE.md` §5 指向它们。
- 不改代码、不改正式评测资产。

## Acceptance Criteria
- [ ] 两个复算脚本各自运行通过并校验 CSV 哈希。
- [ ] 叙述中的每个数字都能由脚本复算得到。
- [ ] `git diff --check` 通过；扫描确认无凭据、无域名以外的隐私。
