# Phase 1 compatibility probe (2026-08-20)

This probe was run after the user approved execution and before application files
were created. It records the versions actually available from their authoritative
registries; it does not claim that the full build has passed yet.

## Backend

- Java 21 is the required source/runtime level, but the host does not have a
  system JDK or Maven. The Maven Wrapper will therefore be the repository entry
  point and verification can use a Java 21 builder/runtime image when needed.
- Spring Initializr and Maven Central expose the stable Spring Boot release as
  `4.1.0`. The Initializr display name is `4.1.0.RELEASE`, but the published
  Maven coordinates use `4.1.0`; `4.1.0.RELEASE` returns 404 from Maven Central.
- Spring Boot 4.1.0's BOM manages Flyway 12.4.0, PostgreSQL JDBC 42.7.11, and
  Testcontainers 2.0.5. The implementation uses these managed versions rather
  than mixing a 1.x Testcontainers module with the Boot 4.1 test integration.
- ArchUnit `1.5.0` and Testcontainers PostgreSQL are published stable artifacts.
