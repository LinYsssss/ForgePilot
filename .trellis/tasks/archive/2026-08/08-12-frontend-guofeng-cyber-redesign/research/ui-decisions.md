# UI decisions

## D-001 — 选择“墨境书院”作为唯一主方向

- **状态**：Accepted
- **日期**：2026-08-12
- **决策人**：用户
- **决定**：采用 A「墨境书院 / Ink Review Atelier」，并加强水墨、雾场、笔触与印章反馈等动态表达。
- **原因**：轻色宣纸工作面最有利于长时间阅读代码、证据与审查结论；古风辨识度直接，同时仍可用冷青状态光保留克制赛博感。
- **拒绝**：B「星宿夜巡」与 C「玉衡机关」不再作为并行主风格；不得把暗色天象台或游戏 HUD 语言混入主界面。
- **可逆边界**：交互原型批准前，纸面明度、侧栏宽度、朱砂/冷青比例与环境墨迹强度可调整；整体方向和三层架构不再重开。

## D-002 — 允许重构前端实现架构

- **状态**：Accepted
- **决定**：不要求遵循现有页面/组件目录和 Element Plus 可视层结构；允许重组路由壳层、页面布局、组件边界、主题系统与状态组织。
- **必须保留**：后端 API、认证/权限语义、关键业务流程、路由可达性与现有数据含义，除非另立任务审批。
- **迁移策略**：Vue 3 + Vite + Vue Router 保持不变；新代码按 feature-first 组织，旧页面通过纵向切片逐步替换，禁止在同一提交无差别重写全部页面。
- **后果**：允许替换现有表现层组件；Element Plus 仅作为过渡或底层能力，页面不得直接依赖其内部 DOM/主题细节。

## D-003 — 水墨动效属于可移除环境层

- **状态**：Accepted
- **决定**：水墨雾、纸纹、山形、笔触与鼠标视差只存在于 `InkAmbientScene` 或一次性状态反馈中。
- **禁止**：代码、表格、正文、表单、焦点和关键动作持续移动、模糊、扭曲、墨化或故障闪烁。
- **降级**：reduced motion、coarse pointer、页面隐藏、窗口失焦或性能降级时切换静态构图。

## D-004 — 不以重动画依赖作为起点

- **状态**：Superseded in part by D-006
- **仍有效**：不引入 GSAP、WebGL 或其他重动画依赖；指针观察器保持单一。
- **已取代**：原先对原生 Canvas 的限制被用户新增的动态墨粒需求取代。

## D-005 — 将墨境调整为淡墨云雾

- **状态**：Accepted
- **日期**：2026-08-12
- **决定**：抬高 canvas/paper 明度，降低山水与纸纹浓度，新增三层柔白云带与 38–54 秒慢漂移，使工作台有“在云里雾里”的包裹感。
- **边界**：云层只属于 ambient plane；正文、Diff、控件与焦点仍使用近实色纸面。大面积模糊层不超过 3 个，normal 模式位移不超过 3px；static/reduced/coarse 环境停止漂移。
- **后果**：UI design contract 升至 v0.3 草案，Stage 4 仍未冻结。

## D-006 — 太极水墨、动态墨粒与登录页

- **状态**：Accepted
- **日期**：2026-08-12
- **决定**：将太极作为核心环境品牌符号；使用原生 Canvas 实现低密度动态墨粒；Stage 3 必须包含登录页与登录→工作台入口。
- **登录边界**：账号、密码、错误、SSO/恢复入口和主按钮处于稳定纸面；太极、云雾、墨粒不参与表单布局或状态表达。
- **颗粒预算**：约 30–64 个、DPR ≤ 1.5、低透明慢漂；static/reduced/coarse/hidden/unfocused 停止 RAF。禁止实时流体、高密度粒子和 WebGL。
- **后果**：UI design contract 升至 v0.4 草案，技术设计和原型范围同步扩展；仍需用户与浏览器证据后才能冻结。


## D-007 — 通过原型门并冻结 UI 合同 v1.0

- **状态**：Accepted
- **日期**：2026-08-12
- **决定**：用户在原型提交 `366d8e0` 与草稿 PR #4 的视觉确认节点回复“继续”；结合 1440/1279/768/390 真实 Chrome QA，Stage 3 通过，`research/ui-design.md` 冻结为 v1.0。
- **修订**：desktop/tablet 边界统一为 1280px；768–1279 保留案卷索引、朱批转抽屉；≤767 双抽屉；移动朱批入口固定在 sticky topbar。关闭抽屉必须 `inert` + `aria-hidden`。
- **后果**：生产 Vue 重写可开始；后续新增令牌、改变信息架构/断点/动效预算或弱化降级行为，必须新增决策并通过 drift gate。
