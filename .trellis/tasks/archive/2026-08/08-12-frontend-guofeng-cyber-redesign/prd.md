# 前端产品重构：古风赛博动态审查台

## Goal

将 RepoSage 从通用 Element Plus 管理台重构为有明确品牌辨识度的“古风赛博代码审查工作台”：用户能在沉浸但克制的动态氛围中快速理解仓库状态、风险、证据与审批动作，同时不牺牲代码 Diff 的可读性、交互稳定性、无障碍和性能。

## Users and core jobs

- 开发者：查看变更、AI finding、证据与修复建议，完成复核。
- 审查者/负责人：判断风险、追踪审查进度并执行审批或驳回。
- 管理者：观察项目、模型调用与 Agent 运行状态，定位异常。
- 核心路径：进入工作台 → 定位待处理项 → 阅读证据/Diff → 执行复核动作 → 获得成功或失败反馈。

## Scope

### In scope

- 重构全局壳层、导航、视觉令牌、页面层级、交互状态与响应式布局。
- 先以“Agent 审查工作台”做纵向切片，再扩展到仪表盘、项目、仓库、PR、知识库、审查记录与 AI 日志。
- 视觉方向已选定为 A「墨境书院」；围绕宣纸、松烟墨、朱砂批注、矿物冷青与克制赛博状态建立统一系统。
- 引入太极水墨、低密度动态墨粒、纸纹、远山、淡墨雾、笔触进度、墨色晕染、朱印反馈和受限鼠标视差；装饰始终与信息层

- 重构登录界面，形成登录门禁 → Agent 审查工作台的完整首次使用路径。
- 保留 Vue 3、Vite、Vue Router、后端 API、认证/权限语义与业务数据含义；允许重组目录、页面、组件、主题、状态和 Element Plus 使用方式。

### Out of scope

- 后端接口、权限模型、评测语料和提示词逻辑重构。
- 将代码 Diff、表格正文、表单控件或关键操作做持续位移、模糊或故障闪烁。
- 默认引入 GSAP、WebGL、Three.js 或大体积动画依赖；只有原生 CSS/Pointer API 无法满足且有性能证据时另行决策。
- 在 Agent 工作台交互原型与设计合同未冻结前批量改写全部页面。

## Product principles

1. **先审查，后氛围**：风险结论、证据、代码和动作永远位于稳定的高对比内容平面。
2. **古意来自秩序，不来自贴图堆砌**：通过留白、书画章法、印记、纸墨材质与命名表达东方气质，不使用景区式龙纹、灯笼或仿古按钮。
3. **赛博用于状态编码**：霓虹青、朱砂红、琥珀金只承担交互、告警、通过与观测状态，不做无语义渐变。
4. **动效可解释且可关闭**：每个动效对应空间、状态、反馈、注意引导或品牌愉悦；支持 reduced motion、触屏和低性能降级。
5. **契约稳定、实现可重构**：保持 API、权限和任务语义，允许替换表现层架构；以纵向切片验证后再扩面。

## Requirements

- 全局导航在 390px、768px、1440px 下保持主要入口可发现；Agent 工作台清晰呈现任务上下文、运行阶段、风险、证据/Diff 与主操作。
- A「墨境书院」是唯一活动方向；完成 1440/768/390 原型后冻结背景、文字、风险、纸面、墨迹、模糊、阴影、字号、间距和层级令牌。
- 中文正文使用高可读字体；展示性古风字体仅用于品牌字或极短标题，并有本地回退。
- 鼠标视差只作用于非信息水墨背景层，最多三层、最大位移 3/6/10px；更新只涉及 transform、opacity 或合成层属性。
- hover/focus/press 反馈 120–240ms，页面/面板入场 240–480ms，不得阻塞操作或造成布局偏移。
- `prefers-reduced-motion: reduce` 时关闭视差、漂移、粒子和大范围入场；触屏/coarse pointer 使用静态构图；页面不可见时停止动画循环。
- 模糊效果提供不依赖 `backdrop-filter` 的近实色回退；动效脚本或背景资源失败时关键内容仍完整可用。
- 正文对比达到 WCAG AA，焦点可见，键盘顺序和弹层焦点正确，触控目标至少 44×44px。
- 保持现有路由、认证、数据获取与业务动作兼容；API 合同变化必须单独提案。
- 覆盖 default/hover/active/focus-visible/disabled/loading 与 empty/error/success/permission/offline/long-content 状态。
- 新前端采用 feature-first 模块边界；页面不直接访问 HTTP，水墨环境层不持有业务数据，新模块优先 TypeScript。

## Constraints

- 当前仓库存在未提交的 R7 评测语料改动；本任务实施必须在 R7 安全落盘后使用独立 `codex/` 分支或工作树，不与其混合提交。
- 当前前端要求 Node `>=22 <23`；本机审计检测到 Node 24，正式构建与验收使用 Node 22。
- Element Plus 不再是可见设计语言的强制基础；可保留、包装或替换，但必须通过 `shared/ui` 稳定行为与无障碍合同。
- A 方向、交互原型与 UI design contract v1.0 已通过并冻结；生产扩面仍必须先完成 Agent + Reviews 纵向切片质量门。
- 禁止 AI 紫粉渐变、emoji 图标、低对比透明正文、全屏毛玻璃、游戏式 HUD、景区古风、书法正文和无语义故障闪烁。
