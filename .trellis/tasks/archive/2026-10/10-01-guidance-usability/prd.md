# AI 实现建议：可读输出、版本一致性与复制导出

## Goal

让开发者知道先做什么、哪些条件待确认、怎样检查完成，以及建议基于哪份已保存内容。2026-10-01 用户已批准：复核计划无阻碍后实施，最小改动。

## Scope

R1 输出：保留 checklist/rules/risks 字符串数组，新增 summary/questions；服务端返回 guidanceVersion=guidance-2。步骤要求说明动作、适用 AC 与验证办法；不硬挂 AC、不编造仓库实现，允许信息不足时没有步骤。

R2 版本一致性：未保存/未发布内容不能生成；保存成功（包括 DRAFT 同 revisionId）使旧建议与在途请求失效；晚到的 success/catch/finally 不影响当前页面。结果版本不匹配时明确提示刷新重试。

R3 阅读：概览、待确认、编号步骤、规则与风险优先展示；知识来源默认折叠，相似度不是正确率。生成状态明确；同一内容重新生成失败保留上一份有效结果并说明。

R4 复用：复制建议和下载 Markdown 使用同一文本，携带需求/修订/建议版本及参考资料。复制失败给提示；不新增持久化或历史功能。

## Constraints

- 复用既有 AiGateway、知识召回与权限，一次 embed + 一次 chat，既有网关瞬时重试不变。
- 不新增表、接口、依赖、聊天、自动编码、全仓读取、自动 AC 覆盖度或语义真实性校验。
- 不重构整个需求页，不顺带修改质量检查/上传等其他功能。
- 旧服务缺少新增字段时前端保留旧三组内容，缺失不等于模型判定空结果。
- review-5 和全仓审计的未提交内容全部保留，原任务不归档、不代为提交。
- 冻结评测、迁移、历史数据不动；不自动提交、推送、部署、调用真实模型。

## Acceptance Criteria

- [x] 新输出字段与版本可读、可导出；错误结构不能作为成功空建议。
- [x] 未保存内容不发请求、不自动保存；保存后旧回答不能回流。
- [x] 重新生成失败保留上一份仍适用的建议，等待/失败/缺失字段提示明确。
- [x] 参考资料默认折叠；复制/导出内容一致，失败不声称成功。
- [x] 既有权限、项目隔离、调用次数、不落库边界保持。
- [x] 必要回归、后端完整验证、前端四道门和冻结校验通过；未做的浏览器/真实模型验收明示。
