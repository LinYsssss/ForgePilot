# 论文验收材料与当前文档收口

## Goal

将已完成的指导建议验收整理为可直接引用、可复算摘要的论文材料，并清楚区分当前验证结果与历史快照。本轮仅整理已有证据，不新增模型调用，不改业务代码/UI/依赖/数据库，不重跑正式评测。用户已批准 `/root/.claude/plans/zany-twirling-fern.md` 的收口方案。

## Requirements

- R1：新增论文小节、4 行公开摘要 CSV（1 条历史基线 + 3 条本轮样例）和标准库只读复算脚本。
- R2：完整保留混合结论：程序交互通过，内容目标仅部分达成；条目数下降不等于正文更短，不伪造准确率或效率提升。
- R3：公开材料只含已披露的计数、耗时、来源/域内容指纹及图注；原始回答、知识原文、截图、账号与备份不上传。
- R4：当前状态索引清楚，旧报告保留日期与失败记录；归档后的引用有效，不把实际部署提交改成未部署的新提交。
- R5：CI 复用已有 evaluation job 校验论文摘要，不引入新测试框架或模型凭据；原评分器/holdout guard 保持。

## Constraints

正式评测、旧 CSV、原始证据、迁移和运行代码均不改。guidance-3 工作已先归档，残余内容问题保留。论文新小节只覆盖建议模块的功能验收和输出观察，不代替代码审查效果实验或全站浏览器测试。

## Acceptance Criteria

- [x] 新小节、摘要数据与复算输出一致，数据集哈希固定。
- [x] 私有原始数据不进入公开提交。
- [x] 当前状态与历史快照可区分，链接、编码与冻结校验通过。
- [x] 现有四个与新增一个论文复算脚本均通过，CI 完整执行成功。
- [x] 发布准备记录明确：后续 PR 正常合并，禁止强推或绕过保护；应用代码不变，不重新部署。
