# 工作台化改造(前端)

日期:2026-10-17 · 原型:`.trellis/tasks/10-17-workbench-ia/prototypes/`(三张,用户提供,仅作参考)

目标:**把"介绍产品的界面"改成"干活的界面"**。每页打开即见可操作的数据与动作;删掉解释性文案与装饰性标签。**视觉风格、配色、组件、路由与接口保持不变**(沿用 `tokens.css` 与 `base.css` 既有类,新类只用既有 token)。

## 原型给出的方向(结合本系统实际数据后的取舍)

原型一(工作台):4 张计数卡 + "我的待办"表格(任务标题/类型/需要处理的原因/更新时间/操作,带类型标签与"只看待我处理") + 右栏(项目准备清单、正在进行含进度、最近动态、快捷操作)。
原型二/三(需求详情):页头(标题 + 版本徽标 + 编辑新版本)+ 一行状态元信息 + 五个标签(需求内容 / AI 辅助 / 关联审查 / 附件 / 版本记录);左"需求原文"右"AI 工作区"(需求分析:需补充/可优化条目并关联 AC;实现建议:概览/步骤/知识依据)。

采纳其中与真实数据相符的部分;以下调整是刻意的:

- **不造假进度**:原型的 66% 进度条没有数据来源。审查只有 PENDING/RUNNING/COMPLETED/FAILED,
  运行中显示不定态进度条,不显示假百分比。
- **不造假动态**:最近动态由既有行(审查的发起时间、需求的更新时间)派生,文案如实写成
  "发起审查 / 更新需求",不虚构完成时刻。
- **所属项目列**去掉:工作台本身就是项目内视图,重复同一项目名是噪声。
- **项目选择器**移入页头一行(原型在面包屑行),不新造全局选择器。
- **AI 分析口径**:需求分析的条目直接映射现有 `QualityReport`(确定性规则 + AI 条目,可关联 AC),
  不新增字段、不新增接口。

## 硬约束

- 不改 `design-contract.md` 的视觉方向:只用既有 token 与既有类;不新增颜色、字体、断点。
- 不改路由、不改接口、不改产品术语(审查、Finding、验收条件、终局决定)。
- 承重文案(证据锚定、"未再报告 ≠ 已修复"、校准口径、删除留痕说明)一句不删。
- 每步跑:`npm run lint`、`npm run typecheck`、`npm run test -- --run`、`npm run build`。

## 逐页改动

1. **工作台 WorkspacePage**
   - 删:hero 长句与 `hero-signal`;整段「AI 辅助研发链路」与三张能力卡;`lede`、装饰 eyebrow;
     「最近需求」「最近审查」两列表(由待办队列与右栏替代);「项目快捷入口」面板(并入右栏快捷操作)。
   - 换:KPI 四卡(开发中需求 / 待最终决定 / 进行中的审查 / 待发起审查,全部来自现有接口数据);
     「我的待办」队列(开发任务 / 审查任务 / 需求确认 三类,来源:需求状态 × 评审活动 + 当前审查行,
     每行给「需要处理的原因」与动作);右栏四块(项目准备、正在进行、最近动态、快捷操作)。
   - 留:项目选择(进页头)、我的角色、置信度校准面板(压缩口径说明,移到页尾)。
2. **需求详情 RequirementDetailPage**
   - 页头:标题 + v 徽标 + 「编辑新版本」按钮 + 一行状态元信息(状态/评审活动/开发/评审),删 eyebrow 与 lede。
   - 五标签(全部内容留在 DOM,用 `v-show` 切换,既有选择器与测试不破坏):
     需求内容(概览 + 结构化需求 + 状态与指派 + 编辑器)/ AI 辅助(需求质量检查 + 实现建议)/
     关联审查(退回修改 + PR 活动分布 + 覆盖度)/ 附件 / 版本记录。
   - 质量检查条目改为「需补充 / 可优化 / 预算受限」徽标 + 关联 AC,与原型一致;不新增数据字段。
3. **其余页面**:删装饰性英文 eyebrow(14 处)与 `lede`(9 处),长解释压成一句或移入既有 hint;
   功能、按钮、门槛一律不动。
4. **登录页**:删口号式说明与两个 eyebrow,保留表单与一句用途说明。

## 验收

- 页面上英文装饰标签 0 处;不再有 hero/lede 长段;工作台首屏即队列。
- 四道门全绿;与文案相关的测试断言同步更新,其余测试不动。
- 部署 fp-demo 后逐页核对(公网 yasinlin.com)。

## 不做

- 不改配色与视觉语汇、不换主题、不拆两个千行 SFC、不做假进度/假动态。
- 不做列表分页与"待我处理"后端接口(队列在前端由既有接口过滤)。
- 不动设计契约与 89 项浏览器验收基线口径。
