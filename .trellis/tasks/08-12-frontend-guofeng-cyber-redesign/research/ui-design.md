# UI design contract

> 状态：待用户选择视觉方向并批准原型后冻结。本文当前只记录必须定义的合同字段，不代表任何视觉方案已获批准。

## Required contract

- 产品性格、主题原语与禁止项。
- primitive → semantic → component 令牌。
- 字体、布局、断点、组件 anatomy 与交互/数据状态。
- semantic product / themed shell / ambient decoration 三层所有权。
- blur、glow、depth、pointer、motion 的预算与降级。
- mouse、keyboard、touch、reduced motion、page hidden、unsupported feature 行为。
- 可实施示例、反例和设计漂移检查方法。
