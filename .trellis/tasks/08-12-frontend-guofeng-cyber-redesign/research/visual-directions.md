# Visual directions：古风赛博审查台

> 状态：待用户选择。三案共享“古风赛博”主题，但结构、密度与动效隐喻不同；禁止直接混成折中方案。

## 共同基线

- 业务内容位于稳定、高对比、低/无虚化的信息平面。
- 古风通过章法、材质、印记、星图和命名表达；赛博通过状态光、数据线路与实时反馈表达。
- 霓虹色只编码语义；风险红、警告金、通过青、信息蓝配合文本/图标。
- 中文正文使用高可读字体；展示字体只用于品牌或极短标题。
- 装饰层不接收指针事件；持续动效可暂停并支持 reduced motion、触屏与性能降级。

## A — 墨境书院 / Ink Review Atelier

- **结构**：卷轴式纵向阅读；左侧案卷索引，中央稳定审查纸面，右侧浮动朱批结论栏。
- **性格**：克制、文雅、专注；浅墨黑/宣纸灰为主，朱砂红与冷青作为状态印记。
- **组件**：纸页边界、印章状态、批注签、墨迹分隔；避免仿古木纹和写实卷轴贴图。
- **动效**：背景淡墨雾随指针微移；段落切换像墨色晕开，但文字和 Diff 不移动、不模糊。
- **响应式**：移动端收为单卷阅读，朱批栏转底部抽屉。
- **优势/风险**：代码阅读最平静、古风直接；赛博感较弱，浅色纸面与深色代码块切换需谨慎。
- **记忆点**：finding 结论像可验证的“朱批”，状态改变以印记完成。

## B — 星宿夜巡 / Celestial Cyber Watch（推荐）

- **结构**：深色模块化天象台；左侧星官目录，中部高对比审查台，右侧风险/Agent 轨迹观测仪。
- **性格**：沉浸、精密、实时；墨蓝夜空、青玉冷光、朱砂告警、少量琥珀金。
- **组件**：薄边框星图卡片、观测刻度、符箓式数据线路、低强度玻璃层；内容面使用近实色。
- **动效**：三层星尘/雾场视差，指针附近出现克制观测光晕；Agent 阶段沿星轨推进，风险只在变化时脉冲一次。
- **响应式**：桌面三栏、平板双栏；手机保留审查主线，观测仪与轨迹进入可访问抽屉。
- **优势/风险**：最贴合 AI Agent、运行时间线、风险观测和鼠标响应；暗色、模糊与动态治理成本最高。
- **记忆点**：指针像“观星镜”改变远景层，但永远不扭曲内容层。

## C — 玉衡机关 / Jade Mechanism Console

- **结构**：紧凑机关台；主任务固定居中，筛选与元数据嵌入两侧轨道，操作聚合为命令台。
- **性格**：坚实、工程化、权威；墨黑、青玉、氧化铜与琥珀光，几乎不使用紫粉。
- **组件**：榫卯式分区、玉牌标签、青铜刻度、机械闭合反馈；形状更硬朗、密度更高。
- **动效**：面板像机关滑轨，背景玉盘随指针小角度旋转；通过/驳回表现为机构锁定。
- **响应式**：轨道在窄屏重排为步骤式导航，命令台固定在安全区。
- **优势/风险**：企业工作台感最强、操作稳定；容易偏游戏 HUD，必须抑制装饰刻度和拟物。
- **记忆点**：复核完成时“玉衡归位”，提供简短、可中断的空间反馈。

## 推荐与选择门

推荐 **B 星宿夜巡**：能把 Agent 时间线、风险观察、AI 日志与鼠标响应统一成同一产品隐喻，最吻合虚化、动态和赛博诉求。实现时必须以稳定近实色“审查台”承载代码与动作。

用户选择后：在本文记录选择日期和批准范围；在 `research/ui-decisions.md` 记录重大决定；制作 Agent 工作台桌面/移动原型；原型通过后冻结 `research/ui-design.md`。

## 设计检索结论

- 可采纳：深色主场、模块化卡片、中文高可读字体、分层环境光、transform/opacity 动效、清晰 focus-visible。
- 需修正：生成建议中的 AI 紫/粉渐变不符合 RepoSage 风险语义；字体与动效不能照搬游戏或营销页。
- 强制：WCAG AA、`prefers-reduced-motion`、390/768/1440 响应检查、无 emoji 图标。
