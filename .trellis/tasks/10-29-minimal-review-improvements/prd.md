# 最小化审查与协作改进

用户授权：从远程同步最新计划，最小化完善后直接实施。依据 `docs/plans/2026-10-29-minimal-review-improvements.md`，顺序 A → B → C。

验收：候选类别/解释/建议进入综合；合法回答的漏答、无证据 COVERED、零受审文件 AC 变为 UNKNOWN 并告警，格式/Provider 失败仍失败；旧三值报告可读。既有台账按 model/useCase 显示累计尝试，错误/缺失 Token 不冒充零。保留通过合并/退回，补拒绝关闭及必要 PR 状态同步，原权限、版本、一次性决定和跨系统结果确认保持生效。

边界：一条引擎；不增加模型阶段、调用限制、计费、导航、表、抽象层或恢复系统。C 最多追加一份迁移。冻结实验、历史报告和无关本地资产不改。只复用现有 fixture/测试框架验证承重行为，不执行真实模型调用或线上 PR 合并/关闭。
