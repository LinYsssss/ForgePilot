# 订单业务流程（节选）

> 适用范围：acme-shop 订单服务

## 发货规则（重点）

发货前必须**同时**满足：

1. 订单存在且未被逻辑删除；
2. `pay_status = PAID` —— **支付状态与订单状态是两个独立字段，必须分别校验**（订单可能处于 `WAIT_SHIP` 而 `pay_status` 仍为 `UNPAID`，例如支付回调延迟或退款进行中）；
3. `status = WAIT_SHIP`；
4. 收货地址已填写且未被风控标记。

发货成功后：`status` 置为 `SHIPPED`，写入 `shipped_at`，并记录操作人。

> 历史事故 EVAL-101 就是发货逻辑只判断了 `status` 没判断 `pay_status`，导致未支付订单被发货。**批量操作与单笔操作执行同一套前置校验，不得裁剪。**
