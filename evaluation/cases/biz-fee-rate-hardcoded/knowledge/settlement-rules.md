# 商户结算业务规则（节选）

> 适用范围：acme-clearing 结算服务
> 最近修订：2026-05（费率下调后同步）

## 费率

| 商户类型 | 费率 | 说明 |
|---|---|---|
| 标准商户 | 0.6% | 2026-05 由 0.8% 下调 |
| 大额商户（月流水 ≥ 500 万元） | 0.38% | |
| 公益类商户 | 0% | 需资质审核 |

**费率不得硬编码在代码中**，必须从 `fee_rate_config` 表读取，以便运营调整。

历史上曾发生费率调价后代码未同步、按旧费率多收商户手续费的事故（EVAL-207），属合规问题，此后列为红线。
