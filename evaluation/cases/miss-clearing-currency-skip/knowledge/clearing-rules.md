# 清分业务规则（节选）

> 适用范围：acme clearing 清分域。本文为评测用裁剪副本。

## 1. 金额与精度

所有金额一律以「分」为单位，使用 long 存储与计算，禁止浮点；外部「元」
金额在入口层用 BigDecimal 精确转换，超精度拒绝。手续费向下取整，差额
平台承担（复盘编号 EVAL-2025-03）。

## 2. 结算状态机

PENDING → PROCESSING → SUCCESS / FAILED。只有 PENDING 可被发起；发起
时必须显式流转到 PROCESSING；重复发起依赖幂等键拦截。

## 3. 币种（红线）

**当前仅支持人民币（CNY）。任何非 CNY 的清分请求必须在服务层拒绝，
不得按 1:1 汇率处理。**

历史事故（复盘编号 EVAL-2025-08）：灰度商户误传 USD，系统按 1:1 入账，
形成 6.4 倍资损敞口。此后规定：币种校验必须落在清分服务层（而非仅入口
层），新增清分通道时该校验为上线检查单必查项。

## 4. 最小清分金额

单笔净额低于 100 分不发起，累计到下一周期。
